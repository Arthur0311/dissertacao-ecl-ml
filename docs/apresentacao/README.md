# Apresentação

- `apresentacao-fragmento-artefato.html`: fonte publicada como artefato no claude.ai (sem `<html>/<head>/<body>`, que o host adiciona).
- `build.sh`: gera o arquivo autônomo `docs/index.html` a partir do fragmento: `./build.sh ../index.html`.

A apresentação não depende de bibliotecas externas; apenas as fontes são carregadas do Google Fonts (há substitutas do sistema se não houver rede).

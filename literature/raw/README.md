# Exportações originais (imutáveis)

Salve aqui os arquivos **exatamente como exportados** pelo WoS: `wos_Q0_YYYY-MM-DD.xlsx`, `wos_Q0_YYYY-MM-DD.bib`, ... `Q6`. Se houver lotes por limite de exportação, inclua `_parte01`, `_parte02` etc.

Não edite os arquivos aqui. Não sobrescreva pesquisas antigas; use novo nome com data/hora ou versão. Não há dados exportados neste pacote.

Para lotes usar `_lote01`; para nova execução no mesmo dia usar `_exec02`. Registrar hashes, intervalos e contagens por formato. Nunca renomear uma conversão como se fosse exportação nativa. As exceções do Git para XLSX são restritas a `literature/`; avaliar direitos de distribuição antes de publicar metadados.
